# Guardian & Goliath Upgrade

- Guardians now use a procedural futuristic armored silhouette inspired by the supplied blue armored reference.
- Guardian variants retain different colors, sizes and roles while sharing the same futuristic visual family.
- World 39 boss is now the **Guardian Colossus**, substantially larger and tougher, with charge/slam/shock attacks.
- Goliath remains deliberately different: an ancient biblical giant with bronze/leather armor, shield, beard and crest rather than sci-fi armor.
- Reference image is stored at `assets/guardian-reference.jpg`.
- No external model dependency was added.

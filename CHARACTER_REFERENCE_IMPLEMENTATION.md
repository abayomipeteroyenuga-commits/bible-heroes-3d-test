# David Character Reference Implementation

Implemented the supplied cartoon-boy reference as the in-game David visual direction.

- Warm brown open jacket
- Blue inner shirt
- Navy knee-length shorts
- White/gray chunky sneakers with laces
- Blue-gray backpack
- Large swept-up brown hair/quiff
- Large friendly eyes, cheeks and smile retained
- Slightly taller overall silhouette (8%)
- Existing David animation rig, movement, combat and sling APIs preserved
- Supplied reference image stored at `assets/characters/david-reference.jpg` for future art/3D replacement work

The game remains dependency-free: the playable model is procedural Three.js geometry, so GitHub/Vercel deployment does not require an external model server.
